Before you re-deploy

  • Media: gallery images and reel videos are referenced by URL (Google Drive ids are configured in js/config.js), so they are not embedded in the zip.
  • Secrets: js/config.js ships with empty Zainpay and Supabase keys. Add your own before going live — never commit secret keys.
  • Data: the zip carries the schema (.tables/schema.json), not the rows. A fresh deploy starts with an empty database.
  • Keep-alive: .github/workflows/keepalive.yml needs the SITE_URL repository variable set to your live address.
